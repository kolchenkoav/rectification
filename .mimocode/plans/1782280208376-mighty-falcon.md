# Рефакторинг проекта Rectification

## Краткое описание проекта
Spring Boot 3.2.5 веб-приложение для расчета параметров ректификации спирта. Стек: Java 17, JPA, PostgreSQL, Flyway, Thymeleaf, Bootstrap 5. ~764 LOC, 11 Java-файлов.
